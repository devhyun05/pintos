# Pintos

KAIST Pintos를 기반으로 스레드, 시스템 콜, 가상 메모리를 구현한 4주간의 팀 프로젝트입니다. 앞 2주와 뒤 2주는 서로 다른 팀과 진행했습니다.

## 프로젝트 구성

| 기간 | 구현 범위 | 주요 작업 | 원본 저장소 |
| --- | --- | --- | --- |
| 1~2주차 · Team A | Threads, User Programs | `timer_sleep`, Argument Passing, `create`·`write`·`open`·`close` 시스템 콜 | [PINTOS-VM](https://github.com/tail1887/PINTOS-VM) |
| 3~4주차 · Team B | Virtual Memory | `mmap`·`munmap`, 파일 기반 페이지 처리 및 예외 검증 | [pintos](https://github.com/devhyun05/pintos) |

## 작업 이력

팀이 변경된 시점을 기준으로 커밋 이력이 두 저장소에 나뉘어 있습니다. 팀원별 기여가 유지되도록 기존 커밋과 작성자 정보는 원본 그대로 보존했습니다.
